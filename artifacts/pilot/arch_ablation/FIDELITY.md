## What this is

Deterministic in-process harness. Each arm is a **stack configuration** over
existing Global OS primitives (or a mutable baseline stand-in for B0). Scenarios
inject sealed adversarial conditions and score invariant holds.

## What this is not

```text
≠ independent two-lab LLM replication
≠ Pilot 3 re-run / ATTR overturn
≠ PRODUCTION_PROVEN evidence
≠ proof that recursive org topologies are superior
≠ license to add new T0/T1 surfaces
```

## Integrity rules

| Rule | Enforcement |
|------|-------------|
| Same scenarios for all arms | harness loops sealed SCENARIO_IDS |
| No LLM security boolean | pure Python control flow |
| No silent allow | G2/G3/Gfull use gateway reconciliation / Authority DENY |
| Score from harness only | SCOREBOARD.json emitted by `run_ablation()` |
| Parent ATTR frozen | DECISION must restate Pilot 3 ATTR NOT_SHOWN / M2 CLOSED |

## Breaks → INCONCLUSIVE

Any arm skip, nondeterministic branch, network call, or post-hoc scenario edit
after LOCK without amendment → comparison `INCONCLUSIVE`.
