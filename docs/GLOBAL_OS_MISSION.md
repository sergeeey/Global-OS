# Global OS — Mission

**Миссия:** создать универсальную evidence-governed когнитивную операционную систему, которая принимает человеческую цель, самостоятельно исследует задачу, выбирает допустимые действия и инструменты, выполняет работу, проверяет фактический результат, восстанавливается после ошибок и со временем улучшает свои методы без потери управляемости, безопасности и проверяемости.

**Главный контракт:**

`Human Goal → Investigation → Safe Action → Real Effect → Independent Verification → Truthful Result → Validated Improvement`

**Нерушимые принципы:**

1. Outcome > output.
2. Evidence > self-report.
3. Verification > autonomy.
4. `UNKNOWN / INCONCLUSIVE` > false SUCCESS.
5. Goal completion определяется внешней проверкой, а не окончанием model turn.
6. Простое доказанное решение предпочтительнее сложного недоказанного.
7. Новая capability должна показывать измеримую ценность относительно baseline.
8. Локальный milestone не может подменять Mission DoD.
9. Модель заменяема; Global OS — runtime/control plane вокруг неё.
10. Самоизменение и learning не принимаются без независимой проверки.

**Текущий ориентир:** сначала довести Global OS до реально используемого verified working runtime; adaptive planning, learning и self-improvement развивать только по доказанным bottleneck реальной работы.

**Mission DoD:** пользователь задаёт цель, Global OS самостоятельно доводит её до проверенного реального результата в пределах разрешений, честно сообщает недоказанность/блокер, сохраняет evidence и может улучшать будущую работу только на основании подтверждённого опыта.
